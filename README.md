# Plaqueo Vehicular

Prototipo responsive para explorar remates oficiales de vehículos en Perú mediante un informe interactivo, trazabilidad de fuentes y análisis de rentabilidad.

## Importante

- Los tres vehículos del prototipo son casos **demostrativos**.
- La página no inventa antecedentes ni consulta bases restringidas.
- Los enlaces a SUNAT, SAT Lima y PRONABI llevan a fuentes oficiales.
- “No disponible” no significa “sin deuda”.

## Ver localmente

Abre `index.html` en un servidor web estático. No requiere instalación ni compilación.

## Actualizar los datos

1. Edita el arreglo `vehicles` en `app.js`.
2. Conserva `status: 'Demostrativo'` hasta contar con un aviso oficial verificable.
3. Actualiza la fecha y el estado de cada fuente en `index.html`.
4. Para datos reales, conserva el enlace original y no completes campos ausentes con suposiciones.

## Publicación

GitHub Pages publica los archivos estáticos ubicados en la raíz de la rama `main`.
